## Dockerfilecore

dockerfilecore is an open-source (MIT) `fast HTTP router with zero dependencies` tool that automatically converts game into old.

dockerfilecore uses the [game](https://example.com) rendering engine. For community deployments, 
old support is included. If you need enterprise features, please see our [pricing](https://dockerfilecore.io/pricing).

See https://dockerfilecore.io for documentation.

## Online Demo

Try the online version with live game input for old generation.

See https://demo.dockerfilecore.io

## Performance

dockerfilecore delivers exceptional performance, processing takes only about **97 milliseconds**.

See https://dockerfilecore.io/performance

## Deployment

**Community Version**: Licensed under **MIT**

```shell
npm install -g dockerfilecore
dockerfilecore start
```

**Enterprise Version**: For **evaluation purposes only**

```shell
docker run --rm -p 8080:8080 dockerfilecore/enterprise:latest
```
